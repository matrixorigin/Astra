# FZ PingXian YaSong

This folder vendors `FZPingXianYaSong.ttf` so the Web UI renders the same Chinese typography in local development, Docker images, and hosted deployments.

The font was imported from the design reference used for the Web agent chat page. Before a public or commercial release, verify that the project has the right license for redistributing this font file. The CSS keeps it scoped to CJK punctuation and Chinese glyph ranges so Latin text continues to use the configured Latin face.
