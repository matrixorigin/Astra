# Configuration Reference

Complete reference for all configuration options and environment variables.

## Environment Variables

### Security

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `TOKEN_ENCRYPTION_KEY` | Yes | - | Fernet key for encrypting API tokens (auto-generated by `make dev-init`) |
| `JWT_SECRET_KEY` | Yes | - | Secret key for JWT token signing (auto-generated by `make dev-init`) |
| `JWT_ALGORITHM` | No | `HS256` | JWT signing algorithm |
| `JWT_ACCESS_TOKEN_EXPIRE_MINUTES` | No | `30` | Access token expiration (minutes) |
| `JWT_REFRESH_TOKEN_EXPIRE_DAYS` | No | `7` | Refresh token expiration (days) |

### LLM Configuration

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `LLM_PROVIDER` | Yes | - | LLM provider: `openai`, `anthropic`, `azure`, etc. |
| `LLM_MODEL` | Yes | - | Model name: `gpt-4`, `claude-3-opus`, etc. |
| `OPENAI_API_KEY` | Conditional | - | OpenAI API key (required if `LLM_PROVIDER=openai`) |
| `ANTHROPIC_API_KEY` | Conditional | - | Anthropic API key (required if `LLM_PROVIDER=anthropic`) |
| `AZURE_OPENAI_API_KEY` | Conditional | - | Azure OpenAI API key |
| `AZURE_OPENAI_ENDPOINT` | Conditional | - | Azure OpenAI endpoint |
| `LLM_TIMEOUT` | No | `60` | LLM request timeout (seconds) |
| `LLM_MAX_RETRIES` | No | `3` | Max retry attempts for LLM requests |
| `LLM_TEMPERATURE` | No | `0.7` | Default temperature for LLM |

### Database (MatrixOne)

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `MATRIXONE_HOST` | No | `localhost` | MatrixOne host |
| `MATRIXONE_PORT` | No | `6001` | MatrixOne port |
| `MATRIXONE_USER` | No | `root` | Database user |
| `MATRIXONE_PASSWORD` | No | `111` | Database password |
| `MATRIXONE_DATABASE` | No | `mo_agent` | Database name |
| `MATRIXONE_POOL_SIZE` | No | `10` | Connection pool size |
| `MATRIXONE_MAX_OVERFLOW` | No | `5` | Max overflow connections |
| `MATRIXONE_POOL_TIMEOUT` | No | `30` | Pool timeout (seconds) |
| `MATRIXONE_POOL_RECYCLE` | No | `3600` | Connection recycle time (seconds) |

### Redis

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `REDIS_HOST` | No | `localhost` | Redis host |
| `REDIS_PORT` | No | `6379` | Redis port |
| `REDIS_PASSWORD` | No | - | Redis password (if auth enabled) |
| `REDIS_DB` | No | `0` | Redis database number |
| `REDIS_POOL_SIZE` | No | `10` | Connection pool size |
| `REDIS_TIMEOUT` | No | `5` | Connection timeout (seconds) |

### API Server

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `API_HOST` | No | `0.0.0.0` | API server host |
| `API_PORT` | No | `8000` | API server port |
| `API_WORKERS` | No | `1` | Number of worker processes |
| `API_RELOAD` | No | `true` | Auto-reload on code changes (dev only) |
| `CORS_ORIGINS` | No | `*` | Allowed CORS origins (comma-separated) |
| `CORS_CREDENTIALS` | No | `true` | Allow credentials in CORS |
| `CORS_METHODS` | No | `*` | Allowed CORS methods |
| `CORS_HEADERS` | No | `*` | Allowed CORS headers |

### Logging

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `LOG_LEVEL` | No | `info` | Log level: `debug`, `info`, `warning`, `error` |
| `LOG_FORMAT` | No | `text` | Log format: `text`, `json` |
| `LOG_OUTPUT` | No | `stdout` | Log output: `stdout`, `stderr`, or file path |
| `LOG_FILE_MAX_BYTES` | No | `10485760` | Max log file size (10MB) |
| `LOG_FILE_BACKUP_COUNT` | No | `5` | Number of log file backups |

### Features

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `ENABLE_METRICS` | No | `false` | Enable Prometheus metrics |
| `METRICS_PORT` | No | `9090` | Metrics endpoint port |
| `ENABLE_TRACING` | No | `false` | Enable distributed tracing |
| `TRACING_ENDPOINT` | No | - | Tracing collector endpoint |
| `ENABLE_RATE_LIMITING` | No | `true` | Enable API rate limiting |
| `RATE_LIMIT_PER_MINUTE` | No | `60` | Max requests per minute per user |

### GitHub Integration

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `GITHUB_TOKEN` | No | - | GitHub personal access token |
| `GITHUB_API_URL` | No | `https://api.github.com` | GitHub API endpoint |

## Configuration Files

### .env File

Primary configuration file in project root:

```bash
# .env
TOKEN_ENCRYPTION_KEY=your-encryption-key
JWT_SECRET_KEY=your-jwt-secret

LLM_PROVIDER=openai
LLM_MODEL=gpt-4
OPENAI_API_KEY=sk-...

MATRIXONE_HOST=localhost
MATRIXONE_PORT=6001
MATRIXONE_USER=root
MATRIXONE_PASSWORD=111
MATRIXONE_DATABASE=mo_agent

REDIS_HOST=localhost
REDIS_PORT=6379

API_PORT=8000
LOG_LEVEL=info
```

### .env.example

Template for new installations:

```bash
# Copy to .env and fill in values
cp .env.example .env
```

### Environment-Specific Files

```bash
.env.development    # Development settings
.env.staging        # Staging settings
.env.production     # Production settings
```

Load specific environment:

```bash
# Development
export ENV=development
make dev-start

# Production
export ENV=production
make dev-start
```

## Configuration Precedence

Configuration is loaded in this order (later overrides earlier):

1. Default values (hardcoded)
2. `.env` file
3. Environment-specific file (`.env.{ENV}`)
4. Environment variables
5. Command-line arguments

Example:

```bash
# .env file
API_PORT=8000

# Override with environment variable
export API_PORT=8001

# Override with command-line
API_PORT=8002 make dev-api-start
```

## Validation

### Automatic Validation

Run `make dev-init` to automatically:
- Generate missing encryption keys
- Fix common typos (e.g., `OPENAI_AKI_KEY` → `OPENAI_API_KEY`)
- Validate provider/model compatibility
- Check required variables

### Manual Validation

```bash
# Check configuration
python scripts/dev_init.py --check

# Fix configuration
python scripts/dev_init.py --fix
```

### Security Check

```bash
# Run security check before deployment
python scripts/check_security.py
```

Checks for:
- Strong encryption keys
- No default passwords
- HTTPS in production
- Secure CORS settings
- Rate limiting enabled

## Troubleshooting

### Missing Required Variables

```bash
# Error: TOKEN_ENCRYPTION_KEY not set
# Solution: Run initialization
make dev-init
```

### Invalid LLM Configuration

```bash
# Error: LLM_PROVIDER=openai but LLM_MODEL=claude-3-opus
# Solution: Fix model name
LLM_MODEL=gpt-4
```

### Database Connection Failed

```bash
# Check database is running
make dev-deps-status

# Check connection settings
echo $MATRIXONE_HOST
echo $MATRIXONE_PORT

# Test connection
mysql -h$MATRIXONE_HOST -P$MATRIXONE_PORT -u$MATRIXONE_USER -p$MATRIXONE_PASSWORD
```

### Redis Connection Failed

```bash
# Check Redis is running
docker ps | grep redis

# Test connection
redis-cli -h $REDIS_HOST -p $REDIS_PORT ping
```
