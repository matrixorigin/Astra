# Astra logo

The mark is an **A** crossed by an orbit. The A stands for Astra and the
durable Work it holds. The orbit is the agent runtime loop — context,
decision, execution, evidence, and back to context — passing in front of the
A and behind it. The blue node on the orbit is the running agent.

In the wordmark, the **t** is a plan branch (`├─●`), the same glyph the
Explain Analyze DAG prints.

All files are plain geometry with no font dependency. The mono file uses
`currentColor`.

## Colors

| Role | On light | On dark |
| --- | --- | --- |
| Structure: the A and the lettering | `#0A1A3A` | `#E8F0FF` |
| Runtime: orbit, agent node, node on the t | `#2F6BFF` | `#5B93FF` |
| Background | `#FFFFFF` | `#081225` |

## Rules

- Bright blue is reserved for the parts that run: the orbit, the agent node,
  and the node on the t. Everything else is structure color.
- At 32px and below use the favicon files. Do not scale the full mark down.
- No gradients, glows, outlines, or shadows. Depth comes from the orbit
  passing in front of and behind the A.
