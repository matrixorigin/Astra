# Claude project adapter

The canonical repository-wide source of truth is
[`../AGENTS.md`](../AGENTS.md). Read it in full before making changes, then
follow [`../CONTRIBUTING.md`](../CONTRIBUTING.md) and the owning contract in
[`../docs/design/`](../docs/design/).

Claude-compatible project skills live in [`skills/`](skills/). Read the
matching `SKILL.md` before starting a covered task. The `.agent/skills` tree is
an intentional compatibility mirror and must remain synchronized.

Keep repository-wide architecture, safety, testing, and delivery rules in
`AGENTS.md` rather than copying them into this adapter.
